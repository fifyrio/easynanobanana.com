# 火柴人（Stickman）爆款视频完整工作流 — 操作文档

> 来源：竞品教程视频拆解（14 分钟，8 个步骤），关键帧截图在 `frames/` 目录，文件名 = 原视频秒数。
> 用途：照此流程录制我们自己的教程视频，**把标注 🔄 的环节替换成 easynanobanana.com 的功能**，为网站导流。
> 核心卖点提示：原视频用 Higgsfield 生图，底层模型就是 **Nano Banana Pro**（见 frames/t485.jpg 底部模型选择器）——我们可以直接说"跳过中间商，直接用 Nano Banana"。

---

## 叙事框架（视频前 3 分钟）

原视频的开场结构，已被多个同类爆款验证，建议保留：

1. **钩子**（0:00-0:20）：某频道只发火柴人图片视频，2 个月做到 15 万订阅、1500 万播放、月入 $13,000。"我用 AI 20 分钟复刻了它。"
2. **代入场景**（0:20-1:40）：凌晨 2 点刷到火柴人视频（frames/t30.jpg 是这段的画面风格参考）→ 查频道数据震惊 → 自己尝试却卡在第一步：不会画画，工具全要信用卡（frames/t95.jpg）。
3. **数据佐证**（1:55-2:30）：连举 3 个同类频道的订阅/播放数据，证明利基还在加速。
4. **核心方法论**（2:30-3:15）：**配音优先，画面第二**。先做画面再配音是"碰撞"，先配音再按停顿切画面才有"节奏感"——这是这类频道能爆的真正原因。每个自然停顿就是一次换画面的时机。

## 八个操作步骤

### Step 1：安装基础工具（原视频 3:20-3:38）

原流程:下载安装 Claude Code，注册免费 Claude 账号（frames/t200.jpg："30 秒完成注册"）。

🔄 **我们的版本**：保留这一步不变（Claude Code 是编排器，免费且我们不替代它），但口播改为"这是唯一需要安装的东西"。

### Step 2：连接生图引擎（原视频 3:39-4:38）

原流程：注册 Higgsfield → 进入 MCP and CLI 页面 → 依次在终端执行 3 条命令：安装 CLI、账号授权登录、安装 skill（frames/t245.jpg、t270.jpg）。完成后 Claude Code 就能调用它生图。

🔄 **我们的版本**：这一步整体换成我们的 MCP——官网 `/mcp` 页放同样的三段式命令（安装、`auth login`、装 skill），页面布局可参考 t245 的排版（编号 1/2/3 + 可复制命令框）。这正是 PRD Phase 3 要做的东西。

### Step 3：脚本 + 配音（原视频 4:38-5:55）

原流程：
- 选题方向：深海、太空、历史、原始人类等"黑暗猎奇"叙事题材。
- 脚本用 AI 写（作者在简介里送"脚本 prompt"作为引流钩子）。
- 配音两个选择，作者特别提醒：**ElevenLabs 库存音色最近导致大量频道被取消变现**，要么用 Voice Design 自造独特音色（frames/t310.jpg），要么真人自录（最安全）。

🔄 **我们的版本**：脚本环节接我们的 `ai-prompt-assistant`（或站内"脚本生成器"页）；配音接我们的 TTS（PRD Phase 2）。"独特音色防 AI 标记"这个点保留——正好是我们 TTS 选型时要支持自定义音色的理由。简介送"脚本 prompt"的引流钩子照抄，换成引导注册我们网站领试用 credits。

### Step 4：拿时间戳（原视频 5:55-6:30）

原流程：把配音文件传到 TurboScribe（免费 3 次/天，frames/t365.jpg 上传页、t375.jpg 转录结果），得到带时间戳的逐句文稿——每个时间戳就是一次换画面的位置。

🔄 **我们的版本**：两个选择。(a) 站内做一个"配音转分镜"小工具页（whisper 转录，成本极低，还能吃"audio to storyboard"的 SEO 词）；(b) 短期先让 Claude Code 本地跑 `ffmpeg silencedetect`（我们 Skill 里已写好），口播说"连转录网站都不用开"。建议教程录 (b)，开发完 (a) 后再补一条短视频。

### Step 5：主 Prompt 批量生图（原视频 6:30-7:52）— 全片核心段落

原流程：回到 Claude Code，粘贴"主 prompt"+ 带时间戳的文稿（frames/t400.jpg 可见 prompt 的 STYLE 段）。主 prompt 做两件事：
1. 每个时间戳生成一张图（22 个时间戳 = 22 张图，全自动批量，约 10 分钟）。
2. 锁定画风：**"像小学五年级学生用 5 分钟画的"**——极简涂鸦、纯白背景、无 3D、无光影、故意粗糙。这个"烂画风"本身就是利基的流量密码。

过程中 Claude Code 会多次请求终端权限，点"always allow"即可（frames/t425.jpg、t445.jpg 生成中画面）。

🔄 **我们的版本**：一模一样的体验，只是 MCP 换成我们的 `batch_generate_images` 工具。主 prompt 我们自己写一版（结构：任务定义 + 逐时间戳生图指令 + STYLE 锁定段），作为简介引流资源。**口播强调：底层就是 Nano Banana，别人绕一圈调它，你直接用官方便宜通道。**

### Step 6：审图（原视频 7:52-8:38）

原流程：去 Higgsfield 网页版画廊查看全部生成结果（frames/t465.jpg、t485.jpg），和被复刻频道的原图逐帧对比，画风几乎一致。作者点题："这些频道的秘密从来不是利基，而是每隔几秒换一张图。"

🔄 **我们的版本**：画廊换成我们已有的 `/history` 页。对比段保留——非常有说服力。

### Step 7：下载并按时间戳重命名（原视频 8:38-9:22）

原流程：图片还在云端，对 Claude Code 说"把图片下载到本地，文件名改成各自的时间戳"（frames/t530.jpg 可见按时间戳命名的文件列表）。于是本地文件夹里 `0s.png、6s.png、14s.png…`，剪辑时不用猜哪张图放哪。

🔄 **我们的版本**：我们的 Skill 已内置此规范（`{序号}_{秒数}s.png`），口播说"我们的 skill 自动就是这么命名的，连这句话都不用说"。

### Step 8a：剪辑（原视频 9:22-10:55）

原流程（任何剪辑软件都行，原视频用 Premiere，frames/t585.jpg、t615.jpg）：
1. 配音拖上时间线——它是视频的"脊柱"。
2. 导入整个图片文件夹，按文件名时间戳逐张拖到对应位置，10 分钟视频约 5 分钟剪完。
3. 加分项：下三分之一居中字幕；按剧情章节切换背景音乐（作者送免版权音乐包引流，frames/t640.jpg）。

🔄 **我们的版本**：短期照录（剪辑不是我们的产品）；中期口播可以预告"我们马上上线一键合成，连剪辑软件都省了"（即 Skill 里的 ffmpeg 本地合成，实际上现在就能做到——可作为我们教程对原版的**超越点**：别人 5 分钟手动拖，我们一句话合成）。

### Step 8b：包装上传（原视频 10:55-12:40）

原流程：
- 标题/封面**不要**直接让 AI 凭空生成——去研究同利基爆款的标题封面，再让 Claude 基于爆款迭代出自己的版本。
- 封面直接用视频里的火柴人图（这类粗糙封面反而点击率高），或回 Higgsfield 按 1280×720 生成，文字压到 2-4 个词（frames/t725.jpg 可见封面生成界面，模型同样是 Nano Banana Pro）。
- 标签：让 Claude 生成 500 字符以内的标签列表，上传时粘贴。

🔄 **我们的版本**：封面环节换成我们的 `ai-thumbnail-maker`（现成功能！）；标签/标题迭代让 Claude Code 顺手完成。"研究爆款再迭代"的方法论保留。

## 结尾段（原视频 12:40-14:00）

心态喊话：第一条视频别追求完美、持续迭代、"YouTube 是马拉松不是冲刺"、展示自己的自由生活状态（作者在西班牙海边办公）。这段是转化订阅的关键，建议保留同样的情绪结构。

## 我们录制时的差异化清单

| 环节 | 原视频 | 我们的教程 |
|---|---|---|
| 生图 | Higgsfield MCP（订阅制） | easynanobanana MCP，直连 Nano Banana，按量 credits |

| 引流资源 | 脚本 prompt + 音乐包 | 脚本 prompt + 音乐包 + 注册送 credits |
